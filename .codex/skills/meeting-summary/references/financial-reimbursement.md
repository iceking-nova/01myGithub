# 财务报销

用于整理会议中的报销议题、决策和待办，以及归纳会议材料中已有的报销明细。具体报销范围、额度、材料要求和审批权限，以用户提供的有效制度及明确授权为依据；会议中的建议或个案处理不自动成为通用制度。

## 需要提取的信息

按材料实际包含的内容提取，缺失项标注“待明确”，无需为普通会议总结强制补齐所有字段。

| 信息 | 整理要点 |
| --- | --- |
| 申请信息 | 申请人、所属部门、项目或费用归属 |
| 费用用途 | 业务事由、费用类别、发生日期及必要说明 |
| 金额 | 原币金额、币种、申请金额、核定金额、实付金额，分别记录 |
| 凭证 | 材料明确要求的发票、付款记录、行程或审批记录及缺失情况 |
| 流程状态 | 待提交、待审批、补充材料、已核定、待付款、已付款等材料可证实的状态 |
| 后续行动 | 需要补交或核实的内容、处理人及截止时间 |

仅在任务确有需要时记录敏感付款信息；会议总结通常不展示完整银行卡号、身份证号或无关个人信息。

## 金额与状态的处理

- 区分发生金额、申请金额、核定金额和实付金额，不把其中一种替代另一种。批准报销不等于已经付款。
- 合计只包含范围明确、币种一致且未重复的条目。遇到汇总行与明细行并存，不重复计入；信息不足时说明合计口径或暂不汇总。
- 不将不同币种直接相加。材料未提供折算汇率、日期或规则时保留原币金额，并列为待确认事项。
- 发现疑似重复报销、金额不一致或凭证缺失时，描述具体疑点及待核对内容；没有证据时不直接认定违规。
- 没有提供制度时，不自行填写报销额度、税率、票据有效期、审批层级、提交期限或付款周期。

## 整理报销流程

按照材料中明确的实际流程，记录提交、审批、财务复核、付款等已出现的环节及交接要求。材料未提及的环节不补写为公司规定。

对每个阻塞项写清下一步，例如“补交酒店付款凭证”“确认费用所属项目”“核对申请金额与明细差额”。负责人和截止时间仅采用明确分派或承诺的信息。

材料之间的制度口径冲突时，列出冲突和来源；无法确认适用版本时标注“待财务确认”，不擅自认定哪一份有效。

## 融入会议总结

沿用 SKILL.md 的会议总结结构，将报销内容放入相关栏目，不另行堆叠一份重复总结：

- **讨论要点**：报销事项、涉及金额、业务背景及处理中的主要问题。
- **已确认决策**：明确批准、退回补充、暂缓处理等决定，以及适用的条件和范围；尚未作出的决定不写入此栏。
- **待办事项**：补齐材料、核对差额、确认制度口径等具体行动，保留已明确的负责人和期限。
- **未决问题**：缺失凭证、审批权限不明、金额差异、流程或制度口径冲突。

存在多笔需要对照的报销事项时，可增加“报销事项、申请金额及币种、核定金额及币种、当前状态、缺失材料”的明细表；仅展示与任务有关的列，不把未知金额填成零。

若用户仅要求总结，直接交付总结；不要据此替用户提交报销、审批申请、发送通知或执行付款。
