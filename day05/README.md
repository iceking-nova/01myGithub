# Day05：Hybrid Search 混合检索

`hybrid_search_demo.py` 按完整截图整合示例数据、余弦相似度、DashScope 向量检索、jieba 中文分词、BM25 关键词检索及 RRF 排名融合，依次输出三组检索结果。执行搜索部分放在 `if __name__ == "__main__":` 下。

在项目根目录使用 PowerShell：

```powershell
uv sync
$env:DASHSCOPE_API_KEY = "你的 API Key"
uv run python .\day05\hybrid_search_demo.py
```

向量检索使用 `text-embedding-v1`，需要网络及有效的 DashScope API Key。

## 代码思路

1. 准备查询 `GPT-4 参数量` 和五篇候选文档，列表索引就是文档 ID。
2. 向量检索：把查询与文档转为向量，用余弦相似度衡量语义接近程度，得到第一份排名。
3. BM25 检索：用 jieba 分词，再根据关键词匹配、词频、词的稀有程度和文档长度计算分数，得到第二份排名。
4. RRF 融合：不直接相加两种原始分数，而是根据各自排名给文档加分，每份排名贡献 `1 / (60 + rank)`；`rank` 从 1 开始。将同一文档的贡献相加后重新排序。
5. 输出向量排名、BM25 排名和融合排名，便于对比。

例如某篇文档在向量检索中排第 1，在 BM25 中排第 3，则其融合分数为 `1/61 + 1/63 ≈ 0.03227`。`k=60` 用于平滑名次之间的贡献差距，不是返回文档数量。整个示例在找相关文档，未调用聊天模型生成答案。

可修改脚本中的 `user_query` 和 `documents` 观察排序变化。文档索引从 0 开始；两种检索的分数含义不同，不能直接比较。语料沿用截图中的教学示例，模型参数量等表述未作事实核验。
